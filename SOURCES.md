Original row IDs are retained in the 150-program list. Some are program variants, geographic tracks or different resources from the same provider. In particular, the original B75 title does not establish separate Apple Private Cloud Compute access; its note identifies that limitation. US16 is a private Verizon program, not a federal grant.

Links were checked with unauthenticated HTTP requests on October 29, 2026. Redirects, blocked access and network failures appear in the link-check file. Those results establish only what the request returned, not application eligibility or program availability.

Private workbooks, transcripts, personal details, account handles, credentials, application decisions and receipts are intentionally excluded. This directory does not grant rights to third-party brands, websites or skill content.
