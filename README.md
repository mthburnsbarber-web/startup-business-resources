## How to use it

Browse the Markdown pages, search within a page, or download the CSV/JSON collections. IDs are stable within each collection. Some organizations occur in more than one collection because they serve different purposes; totals count records rather than unique companies.

Check the provider's current eligibility, intake and terms before applying. Historical names and retired routes remain visible so the original lists are complete. A reachable page is not proof that a program is open, free, suitable or accepting submissions. HTTP restrictions and network failures are reported as unverified, not as closure.

This repository contains public resource information. It contains no private applications, passwords, account records or submission receipts. It makes no claim that all programs were applied to, that all platforms have active accounts, or that any security authorization has been granted.
