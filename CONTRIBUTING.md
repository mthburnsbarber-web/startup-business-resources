# Contributing

To add or correct a resource, provide its official public URL, collection, name and a short explanation. Preserve original IDs and mark retired routes instead of silently deleting items from the original lists. Include the date and source for eligibility, price or availability claims.

Never include passwords, API keys, verification codes, private applicant information, application decisions, personal addresses, private correspondence or session links. Use public provider pages rather than applicant dashboards or confirmation pages.
